# Admin Panel Sidebar Icons

This folder contains the icons displayed on the left sidebar navigation in the Admin Panel.

## How to Customize or Change Icons
You can replace any icon in this folder with your own custom `.svg` or `.png` file.
**Keep the file name exactly the same** so the admin panel picks it up automatically!
